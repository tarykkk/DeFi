# Лабораторна робота №1: «Інфраструктура гаманців та криптографія в блокчейн-мережах»

* **Дисципліна:** Технології децентралізованих фінансів (DeFi) та криптовалют[cite: 1]
* **Мережа:** Ethereum Testnet Sepolia (RPC через Alchemy)[cite: 1, 2]
* **Головний репозиторій:** [Повернутися до загального README](../README.md)

---

## 📋 Мета роботи
Ознайомлення з базовими криптографічними принципами побудови блокчейн-систем, програмна генерація криптографічних пар ключів за алгоритмом **Proof-of-Work (PoW)** із заданим префіксом за датою народження, перевірка балансу в testnet та виконання реальної транзакції між згенерованими гаманцями за допомогою стеку **.NET 8.0 (C#)** та бібліотеки **Nethereum**[cite: 1, 2].

---

## 🛠 Технологічний стек
* **Мова програмування:** C# (.NET 8.0)[cite: 1]
* **Криптографічна бібліотека:** Nethereum.Web3, Nethereum.Signer[cite: 1, 2]
* **Інфраструктура ноди:** Alchemy (Sepolia RPC Node)[cite: 1, 2]
* **Середовище розробки:** Visual Studio Code[cite: 1]

## 🚀 Хід виконання роботи

### Етап 1: Підключення до ноди та ініціалізація проєкту
Налаштовано зв'язок із тестовою мережею Ethereum Sepolia через персональний RPC-вузол платформи Alchemy[cite: 1, 2]. Створено консольний .NET-проєкт `TarasyukLab1` із підключенням пакетів Nethereum[cite: 1, 2].

### Етап 2: Програмна генерація гаманця за критерієм Proof-of-Work
Реалізовано алгоритм пошуку публічної адреси гаманця за умовою збігу префікса з днем народження (`0x11`). 
* **Результат пошуку:** гаманець успішно знайдено за **183 спроби**[cite: 2].
* **Публічна адреса (Відправник):** `0x111Ac84F6cD118eCb607945Ec7aB95C06780F4a8`[cite: 2]

### Етап 3: Поповнення балансу (Testnet Faucet)
За допомогою тестового крана баланс згенерованого гаманця поповнено тестовими монетами Sepolia ETH для покриття комісії за газ[cite: 1, 2].

### Етап 4: Проведення транзакції між гаманцями
Спроєктовано програмний переказ коштів у мережі Sepolia. Програма автоматично генерує другий гаманець-отримувач, здійснює транзакцію та виводить оновлені баланси[cite: 2].

* **Хеш транзакції (Transaction Hash):**  
  `0x5ec4b0073131cd7aa26ed66533df9393ba96b03e6bdf82b5f647a95a946cb5f4`
* **Номер блоку:** `11972847`
* **Витрачено газу (Gas Used):** `21000`
* **Статус виконання:** Успішно (1)[cite: 2]
